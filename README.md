# YouCube-GUI-For-CC-Tweaked

These are a few scripts i made for YouCube to add a gui

There are 2 options

- AudioOnly (Which Only allows for audio)

I made this so i could have looping music in my base on repeat. It automatically starts the last song played when the script starts and has looping on always.
 

- VideoMode (Allows for either AudioOnly... Not like the other script, this strictly just plays the song and has a loop on off function. Or Video Mode which plays videos with audio)

Downside to this one (I am working on fixing it) you can only paste links from the advanced computer terminal but i havent made the gui yet for the terminal.

For now just paste the link through terminal and it will still show up on screen


***BEFORE RUNNING THE SCRIPT EDIT THE LUA***

*Change all "CHANGEME" sections there should be 3 to your IPV4 if on lan server IPV6 if on public and portforward your servers on port 5000 for TCP/UDP*

 
**Rename script to** ***"startup"*** **to have script auto start on server restarts**
